# Daylight reallocation and pedestrian safety

This repository contains the curated aggregate data and two independent analysis implementations for the study **“Daylight reallocation and pedestrian safety: A solar-time natural experiment using 24 years of US fatal crashes.”**

```text
data/      Curated aggregate inputs and provenance
R/         Complete R implementation
python/    Complete Python implementation
```

Both implementations start from the same files in `data/`, fit the same estimands, and write language-specific outputs to `results/R/` and `results/python/`. Generated results are excluded from version control.

## Reproduce the analysis

### R

R 4.5 or later is recommended.

```bash
Rscript R/install.R
Rscript R/run.R
Rscript R/run.R --quick
```

### Python

Python 3.11 or later is recommended.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r python/requirements.txt
python python/run.py
python python/run.py --quick
```

Each workflow follows the manuscript order:

1. national main models and road-user contrasts;
2. calendar, estimator, curvature, small-cluster and target-definition analyses;
3. fixed-state and Mississippi registry analyses;
4. matched traffic analyses;
5. two manuscript tables and ten figures.

The five-center analysis combines the main calendar with archived ±70-day placebo calendars to estimate season-specific quadratic backgrounds. The policy-year multiplier analysis enumerates all `2^23` unique Rademacher sign patterns for the fitted 24-cluster influence contributions. Seasonal, statutory-regime, leave-one-year, Arizona support and Alaska inclusion diagnostics are also exported.

## Validate the implementations

```bash
Rscript R/tests/run_tests.R
python -m pip install -r python/requirements-dev.txt
python -m pytest -c python/pyproject.toml python/tests
python python/validate_cross_language.py
```

The R and Python implementations are separate statistical programs rather than one language calling the other. Cross-language validation compares recomputed estimates, intervals, support summaries and diagnostics after both workflows have run.

## Data boundary

The repository distributes study-specific aggregate analytical tables, not the original provider archives or event-level working databases. Original FARS, Mississippi DPS, FHWA, Census and NOAA records should be obtained directly from their providers under the applicable terms. The public workflows fully reproduce the statistical analyses from curated aggregate inputs; source-stage reconstruction is documented but the complete internal data-engineering environment is not packaged. See [`data/README.md`](data/README.md), [`data/BUILD.md`](data/BUILD.md) and [`DATA_USE.md`](DATA_USE.md).

## Main findings reproduced by both implementations

| Analysis | Evening | Morning |
|---|---:|---:|
| Main pedestrian RCR | 0.155 | 0.204 |
| Pedestrian versus other fatal crashes | 0.212 | 0.214 |
| Five-center quadratic pedestrian RCR | 0.144 | 0.191 |
| Main pedestrian RCR with Alaska included | 0.154 | 0.206 |

The exact policy-year multiplier calibration and matched policy-year deletion analyses are written to `results/<language>/estimates/`. Full intervals and plotted data are generated by the workflows.
